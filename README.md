# MTG Forge

Projet statique prêt à être publié avec GitHub Pages.

## Pages
- `index.html` : générateur de proxys.
- `duel-commanders.html` : exploration Duel Commander.

## Navigation
- La barre supérieure de Duel Commander contient **Proxy**, qui ouvre le générateur.
- Le générateur contient un lien **Duel Commander**.
- Le panneau **Explorer** est retiré de la page d'accueil Duel Commander et apparaît uniquement lorsqu'un commandant est ouvert.

## Publication
Dépose ces fichiers à la racine du dépôt GitHub, puis active GitHub Pages dans les paramètres du dépôt (branche principale, dossier `/root`).
